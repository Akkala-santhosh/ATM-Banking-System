#  ATM Banking System (Java)

A console-based ATM Banking System built using Core Java and Object-Oriented Programming (OOP) principles. This project simulates basic banking operations like account creation, login, transactions, and history tracking.

---

##  Features
-  Create Account (with Aadhar, Phone & PIN validation)
-  Secure Login using Aadhar & PIN
-  Deposit & Withdraw Money
-  Check Account Balance
-  Transaction History
-  View Account Details

---

##  Technologies Used
- Java (Core Java)
- OOP Concepts (Encapsulation, Abstraction, Polymorphism, Interface)
- ArrayList (for data storage)
